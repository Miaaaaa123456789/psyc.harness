## ⚡ 后端化更新（第 1 步已完成）

- **持久化**：任务操作（接受/完成/驳回/转交）通过 `POST /api/tasks/[id]/action` 写入 `data/db.json`，刷新/重启不丢失；`GET /api/tasks` 提供全量任务
- **前端**：`lib/store.tsx` 挂载时自动同步服务端状态；操作乐观更新 + POST，失败自动回滚并提示
- **飞书集成**（`lib/server/feishu.ts`）：设置 `FEISHU_WEBHOOK_URL`（群自定义机器人）后，任务状态变更自动推送消息卡片（支持 `FEISHU_SECRET` 签名）；未配置时静默跳过
- **构建模式开关**：默认全栈服务模式（`npm run build` + `npm start`）；`STATIC_EXPORT=1` 恢复纯静态导出（`npm run build:static`）
- **本地运行**：`npm run dev` 或 `npm run build && npm start`（默认端口 3000，`PORT` 可改）
- **演示模式**仍为纯前端模拟（内存内播放，刷新回落到服务端持久状态）

## 四、已知限制与后续建议

1. **git 提交未完成**：本机缺少 Xcode CLI Tools，`git` 不可用。安装（`xcode-select --install`）后执行：
   ```bash
   cd repo && git init && git add -A && git commit -m "feat: 精神专科AI医院运行工作台重构"
   ```
2. **Netlify 部署未执行**：需提供 `NETLIFY_TOKEN`。仓库已含 `netlify.toml`，提供后运行 `npx netlify deploy --prod --dir=out` 即可。当前已用平台内置发布能力上线，效果等同。
3. **状态不持久化**：任务操作/演示进度存于内存（刷新重置），符合演示定位；接入 HIS 后由后端持久化。
4. **任务操作未按角色过滤**：家属端任务中心仍显示操作按钮，建议后续按角色收敛操作权限。

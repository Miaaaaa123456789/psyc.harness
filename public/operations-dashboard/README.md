# 医院经营协同看板（静态发布版）

此目录保存当前线上“医院经营协同 / 营销分析”看板的可复现静态版本。

> **部署位置**：本目录位于 Next.js 的 `public/` 下，随站点发布后由
> **`/operations-dashboard/`** 路由直接访问。
> 内容与仓库根目录的 `hospital-operations-dashboard/` **保持同一份**
> （2026-10-06 由该处整体替换，此前的单文件旧版已废弃）。

## 打开方式

直接用静态服务器打开本目录：

```bash
cd hospital-operations-dashboard
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 数据更新

- 浏览器确认导入的数据会本地持久化；若要作为所有设备共享的基线，请将确认后的日报同步回 `september-revenue-data.js` 并提交。

- **月口径已参数化**（2026-10-06）：主面板走 **2026-10**（`月累计 57.15 万 / 完成 22.0% /
  时间进度 19.4%`）；**9 月整月报告抽屉固定走 2026-09**

  实现：`derive(ym)` / `facts(ym)` 接受可选月份，缺省＝结算月；周序列由 `weeksOfMonth(ym)` 按月推导。

## 模块

`index.html` + 10 个 CSS + 11 个 JS，其中：

| 文件 | 作用 |
|---|---|
| `october-board.js` / `.css` | **10 月经营 / 员工排名 / 9 月报告抽屉**（业主 2026-10-02 新增） |
| `september-report.js` / `.css` | **9 月整月经营分析报告**（右上角绿色按钮 → 右侧滑出抽屉） |
| `month-dashboard.js` / `.css` | 月经营总览（月累计、目标、周度、部门、排名） |
| `marketing-current-report.js` / `.css` | 营销面板内的营业与营销分析报告 |
| `business-analysis.js` / `.css` | 经营问题总览（决策核心） |
| `data-import.js` / `.css` | 唯一数据真源（拖入日报 / 导入覆盖层） |
| `final-enhancements.js` / `.css` | 财务经营分析视角 |
| `marketing-detail.js` / `marketing-redesign.js` | 营销明细与面板外壳 |

`管家A`—`管家E`。生产环境（线上链接）使用真实姓名。

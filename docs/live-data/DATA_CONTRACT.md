# 数据、时间与排名契约 v1

## 时间约定

业务日按Asia/Shanghai，数据库时刻用timestamptz/UTC，API为带偏移ISO8601。日期字段用YYYY-MM-DD，严禁`toISOString().slice(0,10)`截取本地业务日。Excel日期系统1900/1904须读取工作簿元数据；公式用实际重算结果，公式错误/缓存滞后标待核。

每条记录分开保存：业务发生日/事件时间、源表提交时间（缺则null）、源修改时间（若真实提供）、采集时间、核验时间、发布revision。每张指标卡均返回`periodStart/periodEnd/dataThrough/fetchedAt/publishedAt/asOf/coverage/status/sourceIds`。没有可靠时间不猜；“今日抓取”不能显示成“今日业务”。全局只显示来源分布和更新时间，不能拿最新一源时间冒充全部数据截至。

原看板**本期观察窗为两周**，基线10.05—10.18，上一期09.21—10.04；月报和自然周排名是另两种窗口。将`period_weeks=2`与`period_anchor=2026-10-05`存入数据库设置并带版本，不擅自改成周。自然周单独周一—周日；护理周期按实际源定义，不强制套自然周。所有“本周/本期”后必须附范围。由服务端业务时钟和显式筛选生成，不从最大已录日期偷偷改变用户筛选。

环比：先校验同一来源、单位、定义、覆盖天数。进行中前N个自然日对上一窗口前N个自然日，缺日不能跳过找后面的日补齐；两边任一缺日则不输出可比增长率，可列已有值和缺日原因。上一值0时率=null，显示新增/不可比，不显示∞。历史完整周可并列，但不能和进行中总量直接比涨跌。

## 来源优先级与口径

不存在“一张表永远优先”的总规则；按指标登记权威来源，异源冲突进入核验，不自动求平均或取最大。

| 业务指标 | 主来源/粒度 | 必须遵守 |
|---|---|---|
| 全院逐日营业、月累计、预算、预测 | 营收原图经核验的日事实；金额到分 | 门诊＋在院＝日合计，月累计按日和独立校验原图累计；更正不能按累计差倒造某日收入 |
| 门诊量、入院、出院、在院 | 营收日报日事实；医生报表另列 | 出院＝初次＋多次；期内入/出为事件和，在院为期末时点值，不能求和。患者流量不是患者级漏斗 |
| 医生归属收入、在管负荷、排名 | 已出院费用明细＋责任归属/在院表 | 全院营业≠医生归属收入；未结算不捏造收入。名字更正采用版本化身份映射，医生不同名不擅自合并 |
| 护理治疗执行/项目完成率/员工榜 | 实做与应做明细、排班及现行考核文件 | 项目与护士粒度不相加，物理治疗不含团体；汇总率＝sum实做/sum应做。只有六项百分比时只能称简单均值，不能称全组实际完成率 |
| 心理工作量/个人排名 | V4每日简报明细，周个人统计作对照 | 用周表自己选择的起止日逐人逐字段核对，不拿最新日报去比旧周表。管理者与员工分开展示 |
| 心理服务营收 | 有日期的收费/收入事实 | 咨询次数×估计单价禁止代替收入；表头无日期的收入不放进当周/月累计。心理咨询＋治疗费用可按既定医生费用口径合并，不能与V4工作量互当校验 |
| 心理患者对接/排课/团体 | 管床心理师对接＋来访表允许前三sheet | 患者ID/就诊ID/服务事件ID链接；只有数值日报不能声称逐人闭环。团体场次、参与人次与去重人数分别算 |
| 客服随访、标记到院 | 回访台账逐条，工作量台账另列 | 重复随访保留事件，去重患者另列；是否到院缺失=null。标记到院率不等于付费率，不能假定到院都收费 |
| 管家接触/住院/心理/体疗转介 | 患者有效对接表各员工sheet | 未填员工=null，不能按0降榜；业务日期与填报日期区分。转介可多项目，不假定互斥 |
| 渠道到院、推进、收益、周报 | 到院登记＋原渠道表单/负责人粘贴 | 到院人次与去重患者不同。只有真实收费事件/成本才能算收益/ROI；未填收益显示待补，不能按到院数估算 |
| 工娱、新媒体、例会 | 有明确期间的专门源/汇报原文 | 没有原始新记录时保留原信息和日期，不以最新抓取日刷新业务期 |

## 事实、更正与去重

原始版本→规范化候选→校验→已接受事实修订→发布快照；原始层不可变。金额分整数，比例存分子分母及定义，展示才四舍五入。缺项、0、缺日、删除、拒绝执行、未填报是不同状态。

每个事件有稳定ID、来源行标识、内容hash、源版本、业务日、粒度、员工/患者/就诊ID（如可得）。脱敏ID从受控身份表稳定映射，不随排序重编，不只按姓名合并不同患者。旧源仅有姓名时标`identity_unverified`，不得给出精确去重/患者闭环结论。

营收日事实同一日期/权威账套只有一条当前有效版本；重复图不累计两遍，更正追加版本。其他表重复日期/同人不直接删除：可能同日多事件，保留待核。完整源删行须有tombstone和审计；跨期补录触发历史重算，月末锁定数据生成修订申请，不静默改正式榜。

## 所有展示值的统一计算

月营业＝当月已接受日事实之和；缺日不补0，标覆盖率。预算差＝实际－目标（带符号），剩余需完成＝max(目标－实际,0)。时间进度按该指标明确dataThrough，而非上传日；完整月天数自动28/29/30/31。

达标所需日均＝剩余需完成/截至日后月剩余自然日；当剩余0日且仍有缺口，日均=null、状态未达标，不能除0。当前速度日均的窗口必须标注：月累计日均/本期已录日均不可混用。日均缺口＝max(所需日均－同卡标注的实际日均,0)。预测＝实际＋剩余天数×已声明情景日均，缺日/样本过少时降级提示，不能当承诺。目标金额、月份、版本、批准状态都由服务端配置；沿用目标注明暂定。

每个指标在数据库metric_definition注册：id、单位、粒度、source IDs、公式版本、去重规则、时间基准、空值策略、权威范围、依赖列表。每个组件必须绑定metric id，不得在文案中维护第二份结果。增加源或指标应扩依赖与验收清单，不能只改首页卡片。

## 心理组专用核对

周个人统计读取手动周选择器与实际起止日，逐员工对每日简报的七项已有字段求和对照，返回matched/mismatch/missing-source，而非只有总数相同就宣布一致。管床心理师对接需按患者/服务事件链接，核对首次、末次、累计服务与转科/出院；时间缺失显示缺失。每日简报无提交时间时不能算按时率，无患者事件ID时不能证明逐人对应。

## 月内与月末排名

保留各部门现行经确认规则，禁止借本改造自动改权重。业务量/效率参与排序；填报天数和出勤天数只作完整性与可比性提示，除非院方另行批准规则变更。护理源表已有名次与参考算分要标明区别；数据不足时不得宣布正式奖金排名。

月内每次接受事实更新重算受影响部门当月榜和原有本期榜，同分同名次（竞赛排名1,2,2,4），稳定员工ID仅用于同名次展示顺序。规则版本、数据revision、期间、纳入字段、缺失与排除原因同时输出；不同部门不合并总分。未完整填报者保留可见并标暂不可比，不用0罚分。月末锁定保留不可变快照，次月补录走更正申请并生成修订版；解锁/审批有权限与审计。

## AI洞察

确定性引擎先生成变化/风险/缺口，再可选让院内模型压缩表达。每条输出`metricIds/evidence/period/comparisonPeriod/revision/ruleVersion/quality/action`；没有证据的推断标“待核实”，不可写成因果事实。优先级依据可复现阈值与潜在影响配置，不让模型自由改榜、改收入或写回源表。无成本不算利润，无患者串联不算真正转化。指标更新立刻更新确定性洞察；模型旧结论标旧revision或隐藏，不阻塞最新数值。

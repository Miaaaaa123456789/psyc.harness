# 医院经营协同看板（静态发布版）

此目录保存当前线上“医院经营协同 / 营销分析”看板的可复现静态版本。

## 打开方式

直接用静态服务器打开本目录：

```bash
cd hospital-operations-dashboard
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 姓名与隐私口径

本目录为**脱敏版**，与生产环境（线上链接）的三点差异：

1. **员工姓名**：保留姓氏、名以 `X` 代替（同姓重复者加序号）；营销侧 5 位管家统一记为 `管家A`—`管家E`。
2. **患者姓名**：渠道看板到院登记表中的患者一律记为 `患者001`—`患者387`
   （**同一姓名固定同一编号**，故「去重患者」等统计口径与线上完全一致）。
3. **联系方式**：手机号一律以 `1XXXXXXXXXX` 占位；「内部推荐（某人）」记为 `推荐人A`—`推荐人D`。

生产环境使用真实姓名与真实联系方式。
